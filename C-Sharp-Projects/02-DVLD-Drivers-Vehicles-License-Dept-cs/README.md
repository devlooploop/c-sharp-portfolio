## 📌 Project Overview

DVLD (Drivers and Vehicles License Department System) is a real-world desktop application that simulates a driving license management system. It handles processes such as applications, license issuance, and driver management.

This project is part of my C# portfolio and demonstrates practical software development using a **local database system** and layered architecture.

---

## 🚧 Current Status

The project is currently **under development**.

Core features are being implemented and tested step by step.

---

## 🧩 Planned Features

- User login and authentication system  
- Driver management (add, update, delete, search)  
- Driving license application processing  
- License issuance and classification system  
- Different license categories management  
- Local database integration using SQL Server  
- Windows Forms user interface

## 🛠️ Technologies Used
